# 復習リマインダー（PWA版）セットアップ手順

## 入っているファイル
- index.html … アプリ本体
- manifest.webmanifest … アプリの名前・アイコンの設定
- sw.js … オフラインで動かすためのファイル
- icon-180.png / icon-192.png / icon-512.png … アイコン

**6つすべてを同じ場所（同じフォルダ）に置いてください。**

## 公開のしかた（どちらか1つ）

### A. Netlify Drop（いちばん簡単・登録不要で試せる）
1. パソコンで zip を展開し、フォルダを作る
2. https://app.netlify.com/drop を開く
3. フォルダごとドラッグ＆ドロップ
4. 発行されたURLを開く

### B. GitHub Pages
1. GitHubで新しいリポジトリを作る（Public）
2. 6つのファイルをアップロード
3. Settings → Pages → Branch を main / (root) にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開ける

※ どちらも https のURLになります（PWAに必要）。

## スマホに追加する
- **iPhone**: Safariでそのページを開く → 共有ボタン → 「ホーム画面に追加」
- **Android**: Chromeで開く → メニュー → 「ホーム画面に追加」または「アプリをインストール」

## データの引き継ぎ（重要）
- 新しいURLでは、今までのカードや記録は引き継がれません。
- 今のアプリの「設定」→「書き出し」でデータをコピーしておき、新しいアプリの「設定」に貼り付けて「内容を確認して復元」を押してください。
- **iPhoneは、ホーム画面に追加したアプリとSafariでデータが別々に保存されます。** 先にホーム画面に追加してから、そのアプリを開いて復元してください。

## アプリを更新するとき
index.html を差し替え、sw.js の `VERSION = 'fukushu-v1'` の数字を上げてください（v2, v3…）。上げないと、古い版が表示され続けることがあります。

## できないこと
- アプリを閉じている間の通知（通知を送るサーバーが必要なため）。毎日のお知らせは、スマホのリマインダーの利用をおすすめします。
